# 项目与前缀

## 项目是什么

项目把「议题编号前缀」「本地文件夹」「Git 仓库」捆在一起。创建议题时可自动继承开发上下文。

## 项目管理

入口：工具条 **项目管理**，或项目菜单底部管理入口。

可做：

- **新建项目**：名称、可选议题前缀、本地文件夹（可多选）、添加 Git（克隆后加入）
- **修改项目**：更新名称 / 前缀 / 文件夹 / Git 列表
- **删除项目**：可连带清理其下议题（有确认）

## 项目切换

侧栏顶部项目名下拉：

- **全部项目**：跨项目浏览议题
- 指定项目：只看该项目议题
- 支持搜索过滤项目名

## 前缀与编号

- 项目可配置 `keyPrefix`（如 `CURS`）
- 历史议题可能仍是旧前缀（如 `OPEN-*`）
- 新议题按项目内历史最大编号续增

## Git 与文件夹

- **文件夹**：本地路径，创建议题时可作为默认开发上下文
- **Git 列表**：可多次「添加 git…」克隆；克隆后路径进入文件夹，URL 记入 `gitUrls`
