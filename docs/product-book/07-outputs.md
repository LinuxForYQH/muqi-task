# 产出内容（目录书）

## 概念

**产出内容**挂在议题详情「开发上下文」与「活动」之间。

典型形态是一本 **目录书**：

- 一个根目录  
- 多份章节 `.md`（可含子目录，扫描深度 ≤ 3）  
- 用于主动触发总结后的产物沉淀  

## 使用方式

1. **添加产出书**：选择目录（需至少含一个 `.md`）  
2. 面板展示书名卡片与章节数  
3. **点击卡片**：弹层左侧目录、右侧 Markdown 预览  
4. **在编辑器中打开**：跳到对应 `.md`  
5. **↻**：重新扫描章节（文件有增减时）  
6. **×**：从议题移除挂载（不删磁盘文件）  

## 章节识别

- 优先：`README.md` / `SUMMARY.md` / `index.md`  
- 章节标题：文件内首个 `# 标题`，否则用文件名  
- 支持相对路径展示  

## 和附件的区别

| | 附件 | 产出内容 |
| --- | --- | --- |
| 形态 | 单文件上传到扩展存储 | 外链目录书 |
| 阅读 | 打开文件 | 目录 + 预览 |
| 典型用途 | 截图、单据 | 总结书、设计说明 |
