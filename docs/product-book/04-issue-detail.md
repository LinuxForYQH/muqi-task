# 议题详情

详情在编辑器面板打开（侧栏点议题或看板 / 甘特）。

## 主体内容

- 标题、描述（点击编辑）
- 父议题链接 / 子议题列表
- 绑定对话入口（若有 `threadId`）

## 附件

- 添加图片 / 文档（单文件 ≤ 25MB）
- 图片缩略图预览；其他类型打开系统编辑器
- 可删除

## 项目关联

- 下拉切换所属项目，或「不关联项目」
- 展示前缀与项目绑定文件夹

## 属性栏

右侧可折叠「属性」：

- 状态、优先级、标签
- 负责人、日期
- 阻塞 / 被阻塞 / 相关议题
- 同步属性（拉最新并请求 Agent 核对）

## 活动与评论

- 活动流：创建、状态变更、评论、Agent 报告
- 评论支持粘贴 / 拖入截图
- **评论**：仅落库
- **同步处理**：续写已绑定会话并发送，由 skill 拉取最新属性与评论
- **同步对话**：把右侧绑定对话同步进活动列表
