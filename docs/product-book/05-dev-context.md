# 开发上下文

开发上下文决定 Agent / 本地操作默认落在哪些目录。

## 绑定方式

详情页「开发上下文」区块：

| 操作 | 作用 |
| --- | --- |
| 选择文件夹 | 多选本地目录，追加到上下文 |
| 选择 git | 填 URL → 拉远端分支 → clone → 绑定路径与分支 |
| worktree 管理 | 切换已有 worktree，或按分支新建 |
| 打开 Workspace | 把当前上下文文件夹打成 Workspace 新窗口打开 |
| Git 提交 | 对有 Git 的上下文做提交 / 推送 / 切分支 |

## 展示规则

- 普通文件夹：显示末级目录名
- worktree：显示 `仓库名 / 文件夹名`（如 `mydocs / main2`）
- 可单独移除某一路径

## 与项目的关系

- 新建议题：常自动挂上所属项目的文件夹
- 切换项目：若上下文为空或仍等于旧项目文件夹，可同步为新项目文件夹
- 手动改过的上下文不会被随意覆盖
