# 产品概览

## 定位

Cursor Taskboard（任务面板）把议题看板嵌进 Cursor：本地 SQLite 持久化，侧栏列表 + 编辑器详情，并与对话、MCP、Git 工作区打通。

## 核心能力一览

| 能力 | 说明 |
| --- | --- |
| 项目管理 | 多项目、前缀、文件夹与 Git 列表 |
| 议题生命周期 | 状态 / 优先级 / 标签 / 子议题 / 关系 |
| 多视图 | 列表、看板、甘特图、查询 |
| 开发上下文 | 文件夹、clone、worktree、Workspace、提交 |
| 产出内容 | 目录书（多章节 md）预览 |
| 活动与协作 | 评论、截图、同步对话、同步处理 |
| 设置与备份 | 语言、同步 db（本地 / Git） |
| Agent | MCP `issue_get` / `issue_update` / `comment_*` |

## 界面入口

- 活动栏 **Taskboard** 视图（侧栏「任务面板」）
- 标题栏：设置（齿轮）、语言（地球）、打开查询面板
- 工具条：项目切换、项目管理、自动化、新建议题
- 视图切换：列表 / 议题看板 / 甘特图

## 数据存放

- 默认：本机 `globalStorage` 下的 `taskboard.db`
- 附件：同目录 `attachments/`
- 可选：Git 仓库备份整库
