# Git / Worktree / 提交

## 选择 git（议题）

流程：

1. 输入仓库 URL  
2. 拉取远端分支列表  
3. 选分支、父目录、克隆目录名  
4. Clone 完成后写入议题 `worktreePath` 与 `gitBranch`

## Worktree 管理

统一入口（原「创建 / 绑定」合并）：

- **切换**：列出各绑定仓库下已有 worktree，一键切到该路径  
- **创建**：按仓库选分支，创建 worktree，并用新路径替换上下文中的源目录  

按「绑定文件夹所属 git 根」分组，不再只认 `workspaceFolders[0]`。

## Git 提交

对上下文中的 Git 目录：

- 查看变更、勾选文件  
- 提交，或提交并推送  
- 切换已有分支 / 新建并切换分支  

无有效 Git 路径时按钮禁用。
