# 议题与多视图

## 状态流

状态（中文标签）：

1. 待立项（backlog）
2. 等待认领（todo）
3. 处理中（in_progress）
4. 等你确认（in_review）
5. 遇到阻碍（blocked）
6. 完成（done）
7. 取消（canceled）

列表视图按上述顺序分组；默认分组折叠。看板聚焦进行中列；查询页覆盖 backlog / done / canceled。

## 列表视图

- 分组展开 / 折叠
- 子议题可嵌套展示（同状态）
- 右键菜单：状态、优先级、标签、编辑、副本、复制、打开对话、归档
- **归档**当前会将状态设为「取消」

## 议题看板

- 列间拖拽改状态
- 卡片点击打开详情（编辑器面板）
- 侧栏点「议题看板」会在右侧编辑器打开

## 甘特图

- 按开始 / 截止日期画条；未设日期时用创建日估算
- 左侧议题名、时间条、轨道均支持右键议题菜单
- 点击打开详情

## 搜索与查询

- 侧栏搜索：编号、标题、描述、标签
- 查询页：按归档类状态筛选，可在标题栏打开
