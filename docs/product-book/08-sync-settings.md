# 设置与 DB 同步

## 设置入口

侧栏标题栏 **齿轮**：直接打开编辑器「设置」页。

当前选项：

- **同步 db** → 进入同步配置页（可返回设置）

工具条上已不再放「同步 db」按钮。

## 同步 db

### 本地模式（默认）

数据只在本机 SQLite，不访问远程。

### Git 备份模式

配置：

- 仓库地址、分支  
- 是否每天自动备份一次（本地小时 0–23，默认 3 点）  

操作：

- **保存配置**  
- **同步到 Git**（推送）  
- **从 Git 拉回**（覆盖本地前先备份）  
- **合并 Git 到本地**（远端优先 + 本地备份）  

说明：SQLite 为二进制文件，合并策略是「远端优先 + 本地备份」，不是文本三路合并。
