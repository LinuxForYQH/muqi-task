# Cursor Taskboard 产品功能书

> 版本基准：`0.3.118`  
> 用途：把当前产品能力整理成「目录书」，可挂到议题的「产出内容」中直接阅读。

## 这本书是什么

Cursor Taskboard 是 Cursor / VS Code 侧栏任务面板扩展：议题管理、项目上下文、Git / worktree、活动评论、DB 同步，以及 Agent MCP 协作。

## 怎么用

- 在议题详情 → **产出内容** → **添加产出书**，选择本目录 `docs/product-book`
- 或由脚本挂到指定议题后，点击卡片即可查看章节预览
