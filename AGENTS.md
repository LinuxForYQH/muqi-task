# Agent install / Agent 安装

When the user asks to install this extension, do not modify source code. At the repository root run:

用户要求安装本扩展时，不要修改源码，在仓库根目录执行：

```bash
npm run install:local
```

Then tell the user to run `Developer: Reload Window` from the Command Palette. Muqi Task should appear in the left activity bar.

成功后请用户在命令面板执行 `Developer: Reload Window`。左侧活动栏应出现 Muqi Task。

Repo: https://github.com/LinuxForYQH/muqi-task
